# Sade İzle — iPhone mobil arayüzü

Bu depo, mobil ekranlara uyumlu ve GitHub Pages üzerinde çalışabilen tek dosyalık (`index.html`) bir **bağlantı arayüzü** içerir.

## Kullanım
1. GitHub deposunda **Settings → Pages** bölümünü açın.
2. **Deploy from a branch**, **main**, **/(root)** seçip kaydedin.
3. Yayın adresi: https://mehmetdikel.github.io/ChatGPT/
4. iPhone'da Safari ile açın, Paylaş → Ana Ekrana Ekle'yi seçin.

## Sınırlar
- Bu sürüm videoları kendi içinde oynatmaz: dış kaynaktaki dizi/izleme sayfasını açar.
- Kaynak sitenin reklamlarını veya korumalarını devre dışı bırakmaz.
- Kaynak sitenin arama sorgusu için kullanılan URL parametresi doğrulanmadığından arama davranışı kaynak sitede test edilmelidir.
- Bu proje Narto Drama ile ilişkili değildir.

İşlevlerin iOS üzerinde doğrulanması ve gerçek video katalog entegrasyonu sonraki geliştirmeyi gerektirir.
